# Licznik K/M

Prosta apka do liczenia kobiet i mężczyzn (Samsung A55).

## Obsługa
- + / - przy każdym liczniku
- Zapisz - dopisuje wynik do pliku Pobrane/LicznikKM/licznik_zapisy.csv
- Od nowa - zapisuje koniec sesji i zeruje liczniki
- przyciski głośności: głośniej = kobieta, ciszej = mężczyzna (działa też przy zablokowanym ekranie)

## Instalacja
APK do pobrania w Releases. Przy pierwszym uruchomieniu warto zezwolić na powiadomienia i wyłączyć optymalizację baterii dla aplikacji.

## Uwagi
- przy włączonym liczeniu przyciski głośności nie zmieniają głośności
- po restarcie telefonu trzeba raz otworzyć apkę
